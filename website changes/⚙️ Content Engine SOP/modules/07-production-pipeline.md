# Module 07 — Production Pipeline

Governed by `../00-ORCHESTRATOR.md`. Run in order for any pillar / service page. Each step pulls in another module.

1. **Research** — target keyword (Module 02), live SERP recon, read the audience's real words (lexicon / Reddit, Module 01).
2. **Outline** — the journey stage it serves (see `SG experiment/03-architecture/website-architecture.md`), the one problem it fixes, the promise, the proof, the CTA.
3. **Write** — website voice, problem-first, their words, no dashes (Module 01).
4. **SEO pass** — title / H1 / meta / slug / internal links / schema (Module 02, section 3).
5. **Graphics** — an infographic per section, light images with alt text (Module 03).
6. **Motion** — subtle scroll-reveal via the imperative pattern (Module 04).
7. **Design check** — tokens + conventions (Module 05).
8. **QA GATES** — run all gates in the orchestrator; log each pass/fail; fix fails before continuing.
9. **Ship** — add to sitemap, footer, llms.txt; request indexing in GSC.

Do not skip steps. If a step does not apply (e.g. no motion needed), say so explicitly rather than silently dropping it.
