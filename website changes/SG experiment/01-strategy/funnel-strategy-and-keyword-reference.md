## 1. The model (read once, then use the tables)

**TOFU (global):** a free **AI-Visibility / SEO report tool** = the lead magnet. Diagnoses "you're invisible in ChatGPT/Google."
**MOFU:** tool landing pages + programmatic result pages + AEO blog. Capture email.
**BOFU (Singapore-first):** retainers across 4 domains — **SEO, content, ads, outreach** — plus landing-page/dev via **unsafe.design**. Forward-deployed framing, "paid on pipeline."

**Geo split:** tool + AEO content = global capture. Service/retainer pages = Singapore-first closing.

### Guardrails (do not break these)
1. **One wedge at a time.** Ship the AI-visibility tool + its funnel first. Prove ≥3–5 booked calls in 45 days BEFORE building tool #2 or a second domain. This is the anti-sprawl rule.
2. **Only build tools whose USER = a buyer.** AI-visibility checker (business worried about pipeline) = yes. Word counter = no.
3. **Gate + cap the tools.** Email for full report, rate-limit, cache, per-day spend cap. Tools that fire LLM queries cost real money.
4. **Tools are lead magnets, not products.** If a tool needs >2 weeks build or ongoing features, rescope.
5. **No fabricated stats or clients. No em/en dashes.** (Standing site rules.)

## 3. What to build (prioritized, mapped to buckets)

**PHASE A — one wedge (weeks 1–4):**
1. **Free tool:** AI-Visibility / SEO report (Google rank + LLM presence + AEO checklist). Email-gated, capped. → targets Bucket A.
2. **`/ai-visibility-checker/`** hero tool page (Bucket A: ai visibility checker KD5, ai visibility tool $60, ai seo tool KD10).
3. **`/lead-generation-agency-singapore/`** (Bucket B) — first BOFU retainer page.
4. **`/forward-deployed-engineers/`** — global positioning pillar.
5. Funnel wiring: email → report → book-the-fix CTA; dogfood proof block.

**PHASE B — scale the working loop (weeks 4–10):**
6. Programmatic tool **result pages** (each scan = indexable page).
7. Micro-tool #2: **llms.txt generator** (Bucket A, KD 36, on-ICP).
8. SG service pages, KD 0 first: `/social-media-agency-singapore/`, `/sem-agency-singapore/`, `/content-marketing-agency-singapore/`, `/seo-agency-singapore/` (Bucket C).
9. `/b2b-lead-generation-singapore/` (Bucket B).
10. AEO blog set (topics above).
11. unsafe.design upsell: `/high-converting-landing-pages-singapore/` (Bucket D/E).

**PHASE C — clone to next domain (month 3+, only after B converts):**
12. Next hero tool for the next domain (ads or outreach), same playbook.

**Kill gate:** if Phase A books zero qualified calls in 45 days, fix or kill before building more.
