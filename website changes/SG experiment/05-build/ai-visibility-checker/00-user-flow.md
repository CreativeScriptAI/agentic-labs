# Stage 0 — User Flow: AI Visibility Checker

**Status:** awaiting Aditya approval. This is the macro flow (storyboard), NOT copy. Copy comes in Stage 1.

**Page:** `/ai-visibility-checker/` · **Target keyword:** ai visibility checker (KD 5). **Dual nature:** a free-tool landing page (TOFU lead magnet) AND an SEO pillar. The flow must serve two visitors: the **tool-user** (came to scan) and the **SEO-reader** (came from search, will scroll and read).

**The core insight the page sells:** your buyers now ask ChatGPT, Perplexity, and Gemini before they buy. If you are not in those answers, you lose the deal before it starts. The tool shows them they are invisible; we are the team that fixes it.

---

## The two paths through the page

- **Tool-user path:** enter domain → scan → free teaser result → email gate → full report → book the fix.
- **SEO-reader path:** land from search → hook → (maybe run the tool) → read why it matters + what AI visibility is → book the fix.

Both funnel to the same CTA: book a call to fix it.

---

## Section-by-section flow (top to bottom)

**1. Hero + the tool (above the fold)**
- Job: hook on the problem and put the tool right there, zero friction.
- User sees: the uncomfortable headline (your customers are asking AI about you, and you are not in the answer) + a single input ("enter your website") + a "Check my visibility" button.
- User does: types their domain, clicks check.
- The tool IS the hero. No long intro before the input.

**2. Scan / loading state**
- Job: show it is really working, build a little anticipation.
- User sees: live progress: checking Google, asking ChatGPT, Perplexity, Gemini.

**3. Instant result (free, ungated teaser)**
- Job: deliver a real result immediately = the hook pays off.
- User sees: a visibility verdict/score, honest and partial (e.g. "you show up in 1 of 4 places buyers look"). Enough to sting, not the full detail.
- Beat: recognition, mild alarm. "I am not there."

**4. Email gate → full report**
- Job: capture the lead.
- User sees: "Get the full report and how to fix it" + email field.
- User does: enters email → unlocks the full report (on page and/or emailed).
- This is anonymous visitor to lead.

**5. Full report (the detail = the pain)**
- Job: show the gaps, per engine, so the problem feels real and fixable.
- User sees: per-engine breakdown (Google position, presence in ChatGPT/Perplexity/Gemini for their key terms) + an AEO checklist (llms.txt, schema, markdown, crawlable) as red/green items.
- Beat: "there is a lot broken, and I can see exactly what."

**6. Why this matters (stakes + SEO body)**
- Job: make them care. Buyers ask AI first now; if you are not cited, you are invisible while your competitor gets recommended.
- Doubles as: the body content that ranks (what is AI visibility, answer engine optimization) for the AEO cluster.

**7. The fix / primary CTA (convert tool traffic to agency)**
- Job: bridge from "here is your problem" to "we build the fix." The GTM-engineering-team angle: we do not sell you a tool, we fix your visibility for you.
- User sees: "We build the fix" + book-a-call CTA.
- The money moment: tool user becomes a lead for the retainer.

**8. Proof (dogfood, honest)**
- Job: credibility. We ran this on ourselves. Ask ChatGPT about getting more customers with AI, and we come up.

**9. How it works / what we check (transparency + SEO)**
- Job: explain the method (Google + the 3 AI engines + the AEO checklist). Builds trust and adds indexable content.

**10. FAQ (objections + SEO)**
- Job: answer "is it free", "how accurate", "what is AEO", "how do you fix it". Targets long-tail, powers FAQPage schema.

**11. Final CTA**
- Job: last conversion. Two doors: run the check (if they scrolled past it) or book the fix.
